# Ressources officielles

155 manifestes `open77.lua` recensés. Les scripts Lua et autres sources texte sont sous `Code officiel/`. Pour retrouver chaque fichier d’origine et les assets associés, ouvre [l’archive complète](open77-resources-main.zip). [Révision du dépôt](https://github.com/Open2077/open77-resources/tree/51e226ed630c5cd0fcfea1bd3b354148ec299ef0)

Vérifie les dépendances et le build indiqué par la ressource. Le paquet serveur inclut déjà ses ressources système et son mode de jeu par défaut. Le README officiel indique comment ajouter les ressources à `resources.load` et lesquelles démarrer avec `ensure`.
