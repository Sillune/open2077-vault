# Open2077 · Vault Obsidian

Base de référence hors ligne pour héberger un serveur OPEN//77 et écrire des ressources Lua. Les guides et les contrats officiels ont été capturés le 24 novembre 2026.

## Ouvrir le vault

Clone ce dépôt ou télécharge son ZIP. Dans Obsidian, choisis **Ouvrir un dossier comme un coffre**, sélectionne la racine du dépôt, puis ouvre [Accueil Open2077](Base%20Open2077/Accueil%20Open2077.md).

| Section | Contenu |
| --- | --- |
| [Documentation](Base%20Open2077/01%20Documentation/Index%20de%20la%20documentation.md) | Hébergement, configuration, développement de ressources et systèmes de jeu |
| [API Lua](Base%20Open2077/02%20API%20Lua/Index%20API%20Lua.md) | 1 934 entrées, avec des index séparés pour le serveur et le client |
| [Exemples officiels](Base%20Open2077/03%20Exemples/Ressources%20officielles.md) | Ressources Lua, WebUI, gamemodes, bibliothèques et pack RP |
| [Devkit et données](Base%20Open2077/04%20Devkit%20et%20donn%C3%A9es/Index%20Devkit%20et%20donn%C3%A9es.md) | Événements, permissions, schémas, stubs et catalogues de jeu |

Pour une IA avec accès au Web, utilise le [fichier autonome des sources](Open2077%20-%20Sources%20pour%20IA.md). Pour travailler avec les fichiers du vault, commence par les [instructions locales](Base%20Open2077/AGENTS.md).
